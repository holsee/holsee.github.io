A few nights before flying to Kraków I had watched Kresten Krab Thorup
demonstrate Erlubi, which streams the Erlang VM's processes into a
Ubigraph server as a 3D graph. So the lightning talk was that, live:
spawn 5,000 processes, link them, and watch the structure grow in space.
The write-up from the time, with the steps to try it yourself, is
[here](/elixirconfeu-elixir-procs-in-3d/).
